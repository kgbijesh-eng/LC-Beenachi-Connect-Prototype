# LC Beenachi Connect UI Prototype

This is a Milestone 1A clickable UI prototype for LC Beenachi Connect V1.

## Scope

This prototype is for screen flow validation only.

It intentionally does not include:

- Laravel backend
- PostgreSQL database
- Real authentication
- Production API calls
- Payment processing
- WhatsApp automation

## Included Prototype Flows

- Login role selector
- Admin dashboard
- Member dashboard
- Members list
- Member profile
- Basic in-app digital membership card
- Fellowship sponsorship dashboard
- Fellowship queue
- Confirm sponsor group
- Member account ledger
- Payment entry
- Events/meetings
- Announcements
- Documents
- Authorized donor search
- Reports
- Settings / roles

## Run Locally

Install dependencies:

```bash
npm install
```

Start the prototype:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Approval Gate

Do not start Laravel backend or PostgreSQL schema implementation until this prototype or an equivalent Figma clickable prototype is reviewed and approved.
