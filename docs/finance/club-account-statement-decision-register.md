## Approval protocol

An approval must record decision ID, chosen option, rationale, approver identity and authority, date, compatibility impact, and whether prior documents require revision. Approval of DR-001 is mandatory before schema design. DR-002 through DR-017, DR-21, and DR-22 must be resolved before posting-service activation. No implementation milestone may interpret `Pending` as consent.

If an approved decision changes, the contract, API, migration/cutover plan, tests, and rollback analysis must be revised before runtime behavior changes.
